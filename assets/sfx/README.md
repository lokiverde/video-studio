# Sound effects

The audio files are not included: generate your own. `library.json` names each sound and what it is
for, and `candidates/prompts.tsv` holds the exact prompt that made it (any AI sound-effect generator
works, ElevenLabs is what the originals came from). Save each one as `assets/sfx/<name>.mp3`;
`fv.py sfx` lists which are still missing. The talking-head mix plays only the kinds that have a
file in `kit/`.
